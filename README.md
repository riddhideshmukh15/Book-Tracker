# 📚 Book Tracker

## 📖 About the Project
Book Tracker is a simple Python project that allows users to maintain a collection of books. Users can add books by entering the book title and author's name and view their collection along with the reading status.

## ✨ Features
- **Add Book:** Enter a book's title and author's name.
- **View Books:** Display the books added to the collection.
- **Reading Status:** Each book has a default status of "Not started".
- **Empty Collection Check:** Displays a message if no books are available.
- **Exit:** Exit the program using the menu.

## 🛠️ Technologies Used
- Python

## 💡 Concepts Used
- Lists
- Dictionaries
- `while` loop
- `if-elif-else` statements
- `for` loop
- `enumerate()`
- User input using `input()`
- `break` statement

## ⚙️ How It Works
1. Run the Python program.
2. Select option **1** to add a book.
3. Enter the book title and author's name.
4. Select option **2** to view your book collection.
5. View the available book information and reading status.
6. Select option **3** to exit the program.
